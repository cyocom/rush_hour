# Phase 0 Research: FIRST Robotics Watch Experience

## Decision 1: Client Stack
- Decision: TypeScript + React + React Router + Tailwind CSS for a static SPA.

## Decision 2: Team Priority Reordering
- Decision: Use @dnd-kit with keyboard fallback controls.

## Decision 3: Session Persistence
- Decision: Use browser sessionStorage under a versioned key.

## Decision 4: Alert + Conflict Detection
- Decision: Compute overlaps with start/end interval logic against local mock data.

## Decision 5: Testing Strategy
- Decision: Vitest + React Testing Library + Playwright smoke tests.

## Decision 6: Scope Constraint
- Decision: No third-party network integrations in this feature.
